Hangman Game 🎮

Description

This is a simple text-based Hangman Game developed in Python as part of the CodeAlpha Python Programming Internship. The game allows the player to guess a hidden word one letter at a time. The player has a limited number of attempts to guess the correct word before the game ends.

Features

- Random word selection
- Letter-by-letter guessing
- Limited attempts for wrong guesses
- Win and lose conditions
- User-friendly console interface

Technologies Used

- Python 3
- Random Module

Concepts Covered

- Variables
- Loops
- Conditional Statements
- Lists
- Strings
- Functions
- Random Module

How to Run

1. Install Python on your system.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python HangmanGame.py
